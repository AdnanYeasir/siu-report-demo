How to Create an Official Link for Officers

Deploy this file to an intranet, internal server, or secure link

100% Client-Side Law Enforcement Privacy & CJIS Compliance
This single HTML file operates entirely within the officer's local browser memory. No sensitive case info, DMV IDs, VINs, or narratives are transmitted to external servers or cloud databases.

1 Method A: Agency Intranet / Internal Server (Recommended for TLC / NYPD)

Save this single file as index.html and upload it to your internal agency server (IIS, Apache, or a SharePoint document library). You can distribute an official internal URL such as:
https://intranet.tlc.nyc.gov/siu-report

2 Method B: Free & Instant Secure Web Hosting (Cloudflare Pages or GitHub Pages)

You can create a direct public or password-protected web link in 60 seconds:
1. Download this file as index.html.
2. Drag & drop the folder into Cloudflare Pages or GitHub Pages.
3. You receive an instant HTTPS web address (e.g. https://tlc-siu.pages.dev) accessible on any desktop, laptop, or mobile patrol MDT.

3 How Officers Download & Retain Changes

• Final Official PDF: Click "Download / Save PDF". In the browser dialog, select Destination: Save as PDF. The date pickers and signature will be permanently embedded in high resolution.
• Re-editable Drafts: Click "Save Case Data" to download an encrypted-compatible local JSON file (TLC-Case-XXXX.json). Later, any officer or supervisor can click "Open Case" to reload and continue editing.
